# Calculadora DOM

Mini proyecto desarrollado con HTML, CSS y JavaScript para practicar manipulación del DOM.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Renderizado dinámico de botones desde JavaScript
- Manejo de eventos con `addEventListener`
- Uso de estado interno para controlar la calculadora
- Operaciones básicas: suma, resta, multiplicación y división
- Limpieza de calculadora con botón C

## Objetivo del proyecto

Practicar los fundamentos del DOM: seleccionar elementos, crear nodos, escuchar eventos, modificar contenido y actualizar la interfaz.
