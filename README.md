# Calculadora DOM

Mini proyecto desarrollado con **HTML, CSS y JavaScript** para practicar la manipulación del DOM y reforzar conceptos de interactividad en una página web.

## 🧰 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Renderizado dinámico de botones desde JavaScript.
- Manejo de eventos con `addEventListener`.
- Uso de estado interno para controlar la calculadora.
- Operaciones básicas: suma, resta, multiplicación y división.
- Limpieza de la calculadora con el botón `C`.
- Borrado del último dígito con el botón `←`.
- Soporte para números decimales.
- Validación de división por cero.
- Historial simple de operaciones realizadas.
- Estado vacío del historial cuando todavía no hay operaciones.
- Mejora visual de la interfaz aplicando criterios básicos de UX/UI.

## 🎯 Objetivo del proyecto

Practicar los fundamentos del DOM, incluyendo:

- Seleccionar elementos HTML.
- Crear nodos desde JavaScript.
- Escuchar eventos del usuario.
- Modificar contenido dinámicamente.
- Manejar clases CSS desde JavaScript.
- Actualizar la interfaz a partir de un estado interno.

## 🎨 Enfoque UX/UI

Además de la lógica funcional, se trabajó una mejora visual de la interfaz para que la calculadora se vea más clara, ordenada y usable.

Se aplicaron criterios como:

- Jerarquía visual.
- Diferenciación de acciones por color.
- Botón principal destacado.
- Estados visuales de interacción.
- Historial con estado vacío.
- Diseño tipo card.
- Adaptación responsive básica.
